The first public version of Nib: a calm Python editor for people just starting out. Type your code, press Run, and read errors in plain English.

**What works**
- Run with ⌘R and see the output beside your code. Stop a stuck program with ⌘.
- Answer `input()` right in the output, where the question is.
- Errors in plain English that point at the line, with **Go to line** and Python's own message one click away.
- One folder for your programs, saved as you type, with folders, rename and move to Trash.
- Python 3.14 comes inside the app. Nothing else to install, and it never touches any other Python on your Mac.

**Download**
- **Mac:** `Nib_0.1.0_aarch64.dmg` (Apple Silicon, macOS 11 or later). Intel Macs aren't supported in this version.

**Opening it the first time**
Nib isn't signed with a paid Apple developer certificate yet, so macOS warns you once: open the .dmg and drag Nib into Applications. Open it; when macOS says it can't check it, go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.

**Good to know**
This is early software, written mostly by AI coding agents and tested by a human. Expect rough edges, and please [report anything that breaks](https://github.com/anon5376/nib/issues).
